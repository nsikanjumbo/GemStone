# GemStone Certification

A blockchain platform for authenticating precious stones with comprehensive certification, provenance tracking, and trading capabilities for gemologists and collectors.

## Features

- Gemstone authentication and certification
- Discovery year validation
- Origin provenance tracking
- Clarity grading system
- Ownership transfer management

## Smart Contract Functions

### Public Functions
- `certify-gemstone`: Register and certify a precious stone
- `transfer-stone`: Update stone ownership status

### Read-Only Functions
- `get-stone-certificate`: Retrieve stone certification
- `get-gemologist`: Get gemologist's address

## Supported Stone Types
- Diamond, Ruby, Sapphire, Emerald, Topaz, Amethyst

## Clarity Grades
- Flawless, Internally Flawless, Very Slightly, Slightly Included, Included
